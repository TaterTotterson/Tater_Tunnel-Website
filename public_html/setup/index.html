Let's get connected

A little setup.
A way back home.

Start with your VPS, add the Home Agent, then connect your first device.

Step 1 · On your VPS

Give Tunnel a place online.

SSH into your Debian or Ubuntu VPS. Have a domain pointed at it, then run the setup command as a user with sudo access.

Run on your VPS 
curl -fsSL https://raw.githubusercontent.com/TaterTotterson/Tater_Tunnel/main/scripts/tater-vps-setup.sh \
-o /tmp/tater-vps-setup.sh && sudo bash /tmp/tater-vps-setup.sh

The installer walks you through the setup. Choose the path that fits your server:

  • Blank VPS full installSets up the agent, WireGuard, Caddy HTTPS, and firewall rules.
  • Advanced existing VPSInstalls the agent. You manage your existing reverse proxy and firewall.
  • Update existing installRefreshes the code while preserving pairing and device state.
Starting as root on a brand-new VPS?

Run the command without sudo. The menu helps create a sudo user and explains how to reconnect before installing Tunnel.

Fresh VPS, logged in as root 
curl -fsSL https://raw.githubusercontent.com/TaterTotterson/Tater_Tunnel/main/scripts/tater-vps-setup.sh \
-o /tmp/tater-vps-setup.sh && bash /tmp/tater-vps-setup.sh

Keep the pairing code from the installer. Read the full VPS guide for DNS, HTTPS, and firewall details.

Step 2 · At home

Bring your home along.

Run the Home Agent on a computer that can reach the apps you want to use.

macOS appPythonDocker

A little app in your menu bar.

Download the macOS release, open the DMG, and install Tater Tunnel. The app starts the Home Agent for you.

Requires macOS 13 or newer.

Get the Mac app

Run it from your terminal.

With Git and Python 3.11 or newer installed, clone the project and start the Home Agent. Keep it running while you use Tunnel.

On your home computer 
git clone https://github.com/TaterTotterson/Tater_Tunnel.git
cd Tater_Tunnel
python3 -m tater_tunnel.home_agent --host 127.0.0.1 --port 4173

A spot in your Docker setup.

With Docker installed, run the Home Agent with persistent state and config volumes.

On your Docker host 
docker run -d --name tater-tunnel-home \
-p 127.0.0.1:4173:4173 \
-v tater-tunnel-home-data:/data \
-v tater-tunnel-home-config:/config \
ghcr.io/tatertotterson/tater-tunnel:latest home

For routes to other containers, use an address reachable from this container. Its localhost is separate from the host's.

Open http://127.0.0.1:4173/ on the computer running the Home Agent.

Step 3 · Bring them together

Make the first connection.

In your Home Agent, enter the VPS address and the pairing code from the installer.

VPS IP or Domain
https://tunnel.example.com
Pairing Code
The code from your VPS installer
Security Mode
standard

Use your own domain in place of the example. Once the VPS is claimed and connected, you're ready to add a device.

Step 4 · On your phone or laptop

Your home, to go.

  1. Add a device in your Home Agent to generate a WireGuard profile.
  2. Scan its QR or import its config in your device's WireGuard app.
  3. Enable the connection and open the relay health address below.
Open on the connected device 
http://10.88.0.1:4174/api/health

Next, add an app route in your Home Agent and open its displayed Use URL from your device.
